# lowest-price-finder (최저가 찾기)

상품명을 입력하면 **네이버 쇼핑**(스마트스토어, 11번가, G마켓, SSG 등 네이버에 입점한 쇼핑몰)과 **쿠팡**을 함께 검색해서
가장 싼 곳부터 보여주고, 클릭하면 해당 상품 페이지로 이동합니다.

Python 3.9 이상만 있으면 되고, 따로 설치할 패키지는 없습니다.

## 실행

```bash
cd price-compare
python server.py
```

브라우저에서 http://localhost:8000 을 열면 됩니다.
API 키가 없으면 데모 데이터로 화면만 확인할 수 있습니다.

## API 키 설정

`.env.example` 파일을 `.env`로 복사한 뒤 키를 채우세요. 둘 중 하나만 있어도 동작합니다.

### 1. 네이버 쇼핑 (무료, 바로 발급)
1. https://developers.naver.com 에 로그인 → **Application > 애플리케이션 등록**
2. 사용 API에서 **검색** 선택, 환경은 **WEB**, 서비스 URL은 `http://localhost:8000`
3. 발급된 Client ID / Client Secret을 `.env`에 입력

### 2. 쿠팡 파트너스 (승인 필요)
1. https://partners.coupang.com 가입
2. Open API 키는 **최종 승인된 파트너**만 발급받을 수 있습니다 (보통 일정 금액 이상의 판매 실적이 필요)
3. 발급된 Access Key / Secret Key를 `.env`에 입력

> 쿠팡 상품은 네이버 쇼핑 검색에 거의 나오지 않기 때문에 쿠팡까지 비교하려면 파트너스 API가 필요합니다.
> 파트너스 링크로 구매가 이뤄지면 수수료를 받을 수 있지만, 사이트에 "쿠팡 파트너스 활동의 일환으로 수수료를 받을 수 있다"는 문구를 표시해야 합니다.

## 동작 방식

- 네이버와 쿠팡을 동시에 호출하고, 한쪽이 실패해도 다른 쪽 결과는 보여줍니다.
- 중고, 단종, 판매예정 상품은 제외합니다.
- "액세서리 제외" 옵션을 켜면 검색어에 없는 케이스·필름·충전기 같은 단어가 들어간 상품과
  중앙값보다 지나치게 싼 상품(다른 상품일 가능성이 높음)을 걸러냅니다.
- 쿠팡 API 키가 없으면 결과 위에 "쿠팡에서 직접 확인하기" 검색 링크를 보여줍니다.
- 같은 검색어는 10분 동안 캐시해서 API 호출 한도를 아낍니다 (`CACHE_SECONDS`로 조절).

## 알아둘 점

- 표시 가격에는 **배송비가 포함되지 않습니다**.
- "네이버 가격비교"로 표시된 항목은 여러 판매처를 묶은 네이버 카탈로그 페이지로 연결되며, 그 안에서 판매처별 가격을 더 볼 수 있습니다.
- 네이버 검색 API는 하루 호출 횟수 제한(기본 25,000회)이 있고, 쿠팡 파트너스 검색 API는 이보다 훨씬 빡빡합니다.

## 파일 구성

| `.env.example` | API 키 설정 예시 |
